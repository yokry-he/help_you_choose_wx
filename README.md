# miniapp（微信开发者工具版）

这是对当前 Flutter 应用的首版复刻工程，重点覆盖：

- 首页 / 模板 / 历史 / 我的（Tab）
- 决策页（问题 + 选项输入，最多 10 项）
- 结果页（再来一次 / 修改选项 / 返回）
- 本地存储（历史记录、动画开关、低端机降级、主题索引、自定义模板）

## 打开方式

1. 打开微信开发者工具
2. 选择“导入项目”
3. 项目目录选择：`miniapp/`
4. `AppID` 可先用测试号（无则勾选“测试号”）
5. 导入后直接编译运行

## 与 Flutter 版对应关系

- `Provider + Hive` -> `utils/storage.js`（`wx.setStorageSync`）
- 决策逻辑 -> `pages/decision/decision.js`
- 结果与再来一次 -> `pages/result/result.js`
- 历史管理 -> `pages/history/history.js`

## 当前限制（首版）

- 已支持 `canvas` 转盘与彩带粒子，并提供“低性能机自动降级动画”
- 主题色可在“我的”页切换，并联动转盘与结果页视觉
- 首页/模板/历史/我的及底部 Tab 选中色已与主题联动
- 已切换为自定义 TabBar 图标，避免原生 tab 图标资源缺失
- 首页已重做为 Flutter 风格布局（欢迎头图、热门模板、最近记录、统计与小贴士）
- 模板页已对齐 Flutter 风格：内置分类 chips + 双列模板卡片 + 使用统计
- 模板内置数据与分类取自 Flutter `BuiltInTemplates`（含情感/非人类等）
- 模板页支持自定义模板新增/编辑/删除，历史记录支持一键“存模板”
- 我的页支持备份导出/恢复（JSON，覆盖或合并）
- 恢复前会展示预览统计（当前数量、导入数量、恢复后数量）
- 暂未接入云端同步，保持本地离线优先
- 转盘文案排版与视觉细节仍与 Flutter 原版存在差异
